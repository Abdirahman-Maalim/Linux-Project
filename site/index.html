This website is part of the Linux Administration Independent Project. It demonstrates static website hosting with NGINX.

Student Task

Rebuilt from scratch by Abdirahman Maalim on ubuntu-vm (Ubuntu 26.04 LTS). The environment uses two groups (webteam, webaudit) and two users (webadmin, auditor) so that editing rights and read-only review rights are kept separate.
